# パック開封演出 設計書（v1）

ポケポケの開封演出を画面録画からフレーム分解して作成。
Pull Hub モバイル版の開封演出の「正解」として Claude Code に参照させる。

---

## 全体構成（5フェーズ）

| フェーズ | 内容 | 長さの目安 |
|---|---|---|
| 1 | パック選択画面（2D UI） | ユーザー操作待ち |
| 2 | ホワイトアウト遷移 | 1.0〜1.5秒 |
| 3 | 3D空間・パックリング登場 | 1.5秒 |
| 4 | スワイプ選択 → タップでズーム | ユーザー操作待ち |
| 5 | 切り裂き → カード出現 → リザルト | 約3秒 |

---

## フェーズ1：パック選択画面（2D）

- 中央：選択中パックの大きな画像（軽い浮遊アニメ：上下に±4pxをゆっくり往復）
- 下部：プライマリCTA「Open Pack」ボタン
- ※ここはまだ3D不要。通常のReactコンポーネント

## フェーズ2：ホワイトアウト遷移

- CTAタップ → 画面全体が白へフェード（0.6秒、ease-in）
- 白画面の間に裏で3Dシーン（フェーズ3）を読み込む
- 読み込み完了 → 白からフェードアウトして3D空間が現れる（0.6秒）
- 体感：「間」が高級感になる。ローディングを演出に変換する

## フェーズ3：3D空間・パックリング登場

**空間の構成（高級感の核心）：**
- 背景：非常に薄いブルーグレーのグラデーション（上が薄青、下が白）
- 床:光沢のある白い鏡面。**パックの反射が床にぼんやり映る**（反射の不透明度 約30%、下にいくほどフェード）
- 背景に小さな光の粒（パーティクル）が10〜20個、ゆっくり上方向に漂う
- 照明：正面上からのソフトな光。パック表面に控えめなハイライト

**登場アニメ：**
- パック（8〜12枚）が画面外から円形リング（観覧車状の配置）に飛び込んでくる
- 選択中の1枚がリング正面・中央に大きく表示。奥のパックは小さく・薄く
- 登場は全体で約1.5秒、各パックは少し時間差（stagger）をつけて到着

## フェーズ4：スワイプ選択 → ズーム

- 左右スワイプでリングが回転し、隣のパックが正面に来る
- 回転は慣性つき（スワイプの勢いで少し滑ってから止まる）
- 正面のパックは Y軸±3度くらいでゆっくり揺れる（idle motion）
- タップ → カメラがパックに寄る（0.5秒）。同時に：
  - リングの他のパックはフェードアウト
  - 背景が薄ラベンダー〜薄ブルーの単色に変化
  - 床の反射は消える（カードに集中させる）

## フェーズ5：切り裂き → カード出現

コマ送り分析の結果、3つの単純な動きの合成で再現できる：

**5-1. 光のライン（約0.8秒）**
- パック上端から約15%の高さに、水平の細い発光ラインが出現
- 色変化：白 → ピンク/虹色（プリズム風） → 白
- ラインの上下に薄いグロー（にじみ光）

**5-2. 上部パーツの分離（約0.5秒）**
- ラインより上の部分（ヘッダー帯）が切り離され、
  右上方向へ回転しながら飛んで画面外へ（軽いスピン、フェードアウト）
- 残った袋本体はその場に留まる

**5-3. カードのスライド出現（約0.7秒）**
- 袋の中からカードが上方向へスッとスライドして出てくる
- ease-out(最初速く、最後ゆっくり)
- カードが完全に出たら袋はフェードアウト

**5-4. リザルト表示**
- カードが画面中央へ移動・拡大
- 「NEW」バッジが左上にポップイン（スケール 0→1、バウンス）
- カード下にレアリティアイコン
- 左右スワイプで次のカードへ（複数枚パックの場合）
- 最高レアのカードは追加演出（後日設計：背景の光、ホロ反射強化）

## Pull Hub 向けアレンジ方針（ポケポケとの差別化）

- 配色：ポケポケの「白・水色・かわいい」ではなく、
  ダーク基調 + メタリックアクセントで米国向けの高級感に振る
  （床は黒の鏡面、背景はチャコール、光の粒はゴールド寄り）
- 文字は全て英語。絵文字なし
- 効果音・ハプティクスは後日

## 技術メモ（Claude Code 向け）

- 3D: React Three Fiber + drei
- アニメ進行: GSAP timeline（フェーズ5は1本のタイムラインで管理）
- まず /sandbox/pack-opening ルートで単独開発し、完成後に本体へ統合
- モバイル優先（375px基準）。60fpsを維持できない演出は簡略化する
