# Phygitals Reference Notes

## 1. Overall Impression

Phygitals feels modern, premium, collectible-focused, and clearly designed for a US-facing audience. The UI is dark, minimal, spacious, and product-centered. It feels closer to a high-end collectibles platform than a Japanese gacha or oripa site.

The strongest design qualities are:
- premium dark visual tone
- large product imagery
- restrained color usage
- clean card-based layout
- strong sense of ownership, value, and physical redemption
- simple explanation of how the product works
- credible marketplace / collectible platform feeling

Pull Hub should use Phygitals as the main reference for brand tone, visual polish, trust, and premium presentation.

## 2. Elements to Borrow

- Dark premium background with subtle borders and soft contrast
- Large hero visuals that make packs and graded cards feel valuable
- Clean, spacious layout with strong visual hierarchy
- Rounded cards with dark surfaces and minimal visual noise
- Product-first presentation: packs, slabs, boxes, and cards are the main visual focus
- Simple, direct CTA buttons such as “Open Pack”
- Clear category cards for different collectible types
- “Recent Pulls” style activity feed to create social proof
- “How It Works” section to explain the product to new users
- Community / user proof section to increase trust
- Pack detail layout with a large preview on the left and purchase controls on the right
- Buyback badge / cash-back information shown clearly
- Tiered pack selection with prices
- Opening flow that feels cinematic but still clean
- Staged reveal experience: pack selection → partial info → final card → rarity effect
- Final result screen with card image, rarity label, estimated value, and continue CTA

## 3. Elements to Avoid

- Making Pull Hub feel like an NFT-only platform
- Making the UI too cold, empty, or abstract
- Overusing futuristic effects at the cost of clarity
- Excessive black space without enough product information
- Overly aggressive “EPIC PULL” style effects
- Relying too much on animation without explaining odds, value, and inventory
- Making the pack-opening experience feel like a casino
- Copying Phygitals too directly instead of adapting it to trading card mystery packs
- Hiding important purchase information behind visual polish

## 4. Screenshot Notes

### Home Screens

- home-hero-01.png: Use as a reference for the homepage hero section. Borrow the dark premium tone, large product visual, short headline, and primary CTA placement. Pull Hub should use a similarly strong first impression, but with clearer trading-card mystery pack positioning.

- home-pack-categories-02.jpeg: Use as a reference for category cards and horizontal pack browsing. The structure is useful for showing Pokémon, sports cards, One Piece, Yu-Gi-Oh!, and other TCG/sports categories in a clean way.

- home-recent-pulls-03.png: Use as a reference for social proof and live activity. Pull Hub should show recent user pulls to make the platform feel active and credible. This can help users understand what others are receiving without relying on overhyped banners.

- home-how-it-works-04.png: Use as a reference for onboarding. The three-step explanation is very useful for first-time users: open a pack, reveal your card, then keep, ship, or sell. Pull Hub should include a similar section to explain the product clearly.

- home-community-05.png: Use as a reference for community proof and trust-building. User posts, delivery proof, and collector activity can make the service feel more legitimate and less like a random gacha app.

### Pack Detail Screen

- pack-detail-main-01.png: Use as a major reference for the pack detail page. Borrow the two-column structure, large product visual, pack tier selector, buyback badge, quantity selector, and strong open-pack CTA. Pull Hub should adapt this into a mobile-first layout if needed.

### Opening Flow

- opening-pack-selection-01.png: Use as a reference for the first step of the opening experience. The user sees multiple packs and chooses one to open. This creates anticipation without needing excessive effects.

- opening-pack-back-02.png: Use as a reference for the hidden-card / card-back suspense state. Pull Hub can use this kind of visual moment before revealing the card.

- opening-card-info-03.png: Use as a reference for staged reveal. Showing year, category, grade, and rarity before the actual card creates suspense and makes the reveal feel premium.

- opening-result-card-04.png: Use as a reference for the final result screen. Borrow the centered card image, concise card name, rarity label, estimated value, and clear continue CTA.

- opening-epic-pull-05.png: Use as a reference for high-rarity excitement effects. Pull Hub should borrow the idea of celebrating rare pulls, but the final version should be slightly more restrained, premium, and less casino-like.

## 5. How to Apply to Pull Hub

Phygitals should be the strongest reference for Pull Hub’s final visual direction.

Pull Hub should combine:
- Phygitals’ premium collectible platform feeling
- Clove’s oripa pack-opening flow
- Nihon Toreca Center’s business structure for packs, rankings, rewards, points, and results

The final Pull Hub UI should feel:
- premium
- trustworthy
- mobile-first
- collectible-focused
- transparent
- US-facing
- exciting but not cheap
- clean but not boring

Phygitals should mainly influence:
- Home
- Pack detail
- Opening flow
- Result screen
- Collection / vault
- Checkout
- Trust and community sections
- Overall spacing, typography, surface design, and premium tone

## 6. Design Rules Inspired by Phygitals

### Color
Use a dark premium base:
- black / near-black background
- dark gray cards
- subtle borders
- white primary text
- muted gray secondary text
- green only for positive actions such as buyback, value, open pack, or success states
- red only for rare pull excitement or high-impact rarity moments

Avoid:
- rainbow gradients
- cheap gold effects
- excessive red
- noisy Japanese gacha colors

### Layout
Use spacious sections with clear hierarchy:
- large hero visual
- horizontal card sections
- clear section titles
- large product cards
- simple CTA areas
- strong separation between browsing, education, community, and purchase flows

### Typography
Use bold headings and clean body text:
- large bold titles for hero and section headings
- smaller uppercase labels for metadata
- clear numerical hierarchy for prices, values, and buyback rates
- avoid overly playful or game-like fonts

### Components
Important components to create or refine:
- pack category card
- recent pull card
- how-it-works card
- community proof card
- pack tier selector
- buyback badge
- open-pack CTA
- staged reveal screen
- final result card
- value display
- vault / collection item card

## 7. Priority

Priority level: High

Phygitals should strongly influence Pull Hub’s final brand tone and UI polish. It is the best reference for making the product feel credible and premium for a US audience.

However, Pull Hub should not become a Phygitals clone. Pull Hub still needs the excitement and clear pack-opening mechanics of an oripa platform. Use Phygitals for trust, premium design, spacing, and collectible presentation.
