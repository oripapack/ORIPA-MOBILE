# 第1部 CORE(現行強制)

## C-1. ブランドコンセプト — "Midnight Tokyo"

- PullHubは米国向けオリパアプリ。実物のトレカをデジタル開封し、発送 or トレードイン(listed value の 100% を Points で)。
- 世界観は **「深夜0時の東京にある、閉店後も灯りのついた高級カードショップ」**。騒がしいネオン街ではなく、ショーウィンドウの静けさ。
- 三色の意味: **黒=夜、金=価値、ネオン朱=いま起きている瞬間**。
- 和要素(鳥居・富士・桜・カタカナ等)の扱いは**第2部 JAPAN ELEMENTS のレジスター指定**に従う(旧「全面禁止」は 2026-07-31 に置換済み)。
- パレット名の "Neon Torii" は名称。鳥居をモチーフとして使う場合も第2部の調理原則(フラット/ネオン/ポップ)に従う。

## C-2. ペルソナ前提(要約)

米国オリパ顧客は4部族: P1ブレイク民(ライブ配信購買層・最大)、P2ポケモン世代投資家(ノスタルジア+資産)、P3ガチャネイティブ(Z世代、54%がアニメファン)、P4ハイプ転売系(スニーカー文化)。
**N2は全部族が拒絶しない唯一のバランス**のため既定に採用。部族別の尖りはイベントスキン(第4部)で出す。詳細は別紙『米国オリパ潜在顧客 徹底分析』。

## C-4. 色の役割ルール

| 色 | 役割 | 使う | 使わない |
|---|---|---|---|
| `--ph-bg` 黒 | 夜 | 画面の地(面積85–90%) | — |
| `--ph-surface`系 | 灯り | カード/パネル/入力欄 | 全面に敷く |
| `--ph-gold` 金 | **価値** | 価格・主要CTA(1画面1つ)・Hitランク・残高・ロゴのアクセント | 本文/汎用ボーダー/広い背景 |
| `--ph-neon` 朱 | **瞬間** | DROP LIVE・MYTHIC・カウントダウン・開封/レア演出。**面積2%以下・必ずグロー付き**。MYTHIC ティアの表示は常設だが neon の使用を許可する。面積2%以下の条件は変わらない。本則が禁止しているのは CTA・本文・常設ナビ・広い面での使用であり、ティア表示はこれに当たらない | CTA/本文/常設ナビ/広い面 |
| `--ph-success` 緑 | 検証 | 監査済み・在庫残数・成功 | 装飾 |

- 数字は全て等幅フォント: 価格・確率・残数・証明書番号・カウントダウン・残高。
- 金とネオンの同一要素での併用禁止。
- エラーとネオンの区別: エラー=フラット+アイコン+説明文(フォーム/トースト内)。ネオン=グロー+等幅大文字ラベル。

## C-5. 禁止事項(AI味の既定値)

grep対象。1つでも残っていたら差し戻し:

1. `#FFFFFF`(最明色は `--ph-text`)
2. 高彩度2色グラデーション(紫→シアン、シアン×マゼンタ等)を文字・ボタン・広い面に使うこと — 生成AIが統計的に回帰する「AI製の指紋」であり、本項はその再発防止テスト(C1案不採用の教訓)。**例外: MYTHIC開封演出の最終フレームの虹/ホロのみ可(P-2)**
3. glassmorphism = **装飾としての**半透明blurカード(機能的クロームの半透明はC-8で条件付き許可)
4. 絵文字アイコン(💎🔥⚡🎁等)
5. 常時アニメーション(バウンスするCTA・点滅バナー)
6. 「#1」「Insane」「Don't miss out」等の検証不能な誇張コピー
7. 偽の緊急性(実在しないタイマー・在庫)— 法務リスク兼ブランド毀損
8. 和要素のレジスター違反 — 第2部 JAPAN ELEMENTS の **NGレジスター**(漆・和紙・墨等の工芸素材コンセプト、神社の荘厳な写真表現、わびさび的ミニマリズム、筆文字)。OKレジスターの記号であっても、荘厳・写実・工芸的に調理した時点で違反
9. **出典の言えない事実の主張** — 金額・確率・パックの中身・鑑定状態に関する記述で、
   実データや契約に裏付けられていないもの。
   C-5-6 が禁じるのは主観的な誇張(「Insane」「#1」)だが、
   本項が禁じるのは検証可能に見えて裏付けの無い記述
   (「PSA 8+ 保証」「80% buyback」「毎パック鑑定カード1枚」)。
   後者の方が実害が大きい。

   **仮の値を置く必要がある場合は必ず全て行う:**
   - 定数名に MOCK を含める
   - ファイル先頭に「実データ待ち。外部に見せないこと」のコメント
   - KNOWN_ISSUES に記録

   **数値の但し書きは本文に入れる。** 注記やアスタリスクに逃がさない。
   例: 「100%」単独は不可。「100% of listed value, in Points」とする。

   未使用・非表示の文言も対象。参照されていなくても、
   復活する経路がある限り出荷されうる。

## C-6. ティア(ガチャ文法)

ティアは「引きの良さ」を表す。パック側の属性であり、カードの属性ではない。
カードに印刷されているレアリティ(SR / SAR / AR / UR / RR 等)とは別物で、
UIのラベルは "RARITY" ではなく "TIER" を使う。
カードの印刷レアリティは、ティアとは別の欄に表示する。

| ティア | 色 | 形 |
|---|---|---|
| MYTHIC | `--ph-neon` + `--ph-glow-neon` | 塗りつぶしタグ |
| LEGENDARY | `--ph-gold` | 塗りつぶしタグ(`--ph-on-gold` 文字) |
| EPIC | `--ph-gold` | 枠線のみ |
| BASE | `--ph-muted` | 文字のみ |

色を持つのは上位3段のみ。新しい色を追加しないこと。

### 文脈による扱いの違い

同じティアでも、出す場所によって扱いを変える。

**オッズ表(開示)**: 全4段を同じ読みやすさで表示する。
BASE も含め、視認性を落として段を区別しないこと。
BASE は装飾なしの平文、色は `--ph-text`、opacity は 1.0。
開示は全段が等しく読めなければならない。

**カードのバッジ**: BASE は何も表示しない。
当たっていないことをわざわざ書かない。MYTHIC / LEGENDARY / EPIC のみ表示する。

オッズ表もこの4段と同じ段数・同じ名前にする。
画面に表示するティアには、必ず対応する確率が開示されていなければならない。

(開封演出の色エスカレーションは P-2 へ移動 — 演出実装時に適用)

## C-7. タイポグラフィ

### N2ブランド(常設)

| 役割 | 第一候補 | 代替 | 理由 |
|---|---|---|---|
| 見出し | **Fraunces** 500(`font-optical-sizing:auto`) | Newsreader(より編集的で静か) | セリフ=オークションハウスの権威。イタリックは1見出し1箇所まで |
| 本文/UI | **Schibsted Grotesk** 400/500/700 | Instrument Sans / Hanken Grotesk | 温度のあるグロテスク。既定値臭がない(2026-07-31 昇格 — 実装 `sg.font` と一致) |
| 数字・データ | **Spline Sans Mono** 400/500 + `font-variant-numeric: tabular-nums` | IBM Plex Mono(より制度的) | 台帳の語彙。桁が揃わない価格表は信頼を削る |

(日本語書体は P-4、スキン用見出しは P-3 を参照)

### 禁止書体

- Inter / Roboto / Open Sans の単独使用(「選ばなかった」印 = AI味)
- Orbitron / Audiowide / Michroma(「AIのSF既定値」。サイバー系で最初に出てくる安易な選択)
- Playfair Display(高級テンプレの既製品感)

### 組版ルール(サイズ別に必ず変える)

- 字間はサイズ依存: 見出し(32px+)は `-0.01〜-0.02em`、本文は `0`、等幅の大文字ラベルは `+0.12〜0.17em`
- 行間もサイズ依存: 見出し `1.05〜1.12`、本文 `1.6〜1.7`、データ行 `1.4`
- 階層は サイズ+ウェイト+行間 のセットで作る(サイズだけで殴らない)
- 余白・レイアウトは `rem/em` 基準(ユーザーの文字サイズ設定に追従して崩れないこと)
- RN 向けの詳細換算表は T9(PLANNED 着手時の最初のタスク)で作成する — それまで本則は原則として適用

## C-8. モーション・実装済みインタラクション

- 常時動いてよいもの: スラブのフォイル光沢スイープ(5.5s周期・1画面1箇所)、LIVEドットの明滅(1.6s)。以上。
- 開封演出: ここだけ演出全開可(スローダウン→エスカレーション→結果)。心理学的にも「期待」の3秒が価値の中心。
- **開封演出は常にタップでスキップして結果へ**(中断可能性 — 実装済み要件)。演出がユーザーを待たせ始めたら負け。
- **機能的半透明の条件付き許可**: C-5-3 で禁止したのは「装飾ガラスカード」。スクロール下のトップバー/ボトムシート等の**機能的クローム**は `rgba(0,0,0,.72) + backdrop-filter: blur(20px)` まで可。材料の重ねは1層まで、`prefers-reduced-transparency` で不透明化。
- 全アニメーションは `prefers-reduced-motion: reduce` で停止(クロスフェード代替)。
- 未実装のインタラクション物理(押下即応・引くジェスチャ・スプリング・ラバーバンド・触覚同期)は **P-1**(強制外)。

## C-9. 信頼シャーシ・情報開示

- **不変リスト**(スキン・派生版でも一切変更しない): `--ph-bg`の暗さ / `--ph-text`系 / 金=価格・CTA / 等幅数字 / **オッズ台帳・トレードイン(listed value の 100%)表示・証明書番号のUI** / C-5 禁止事項。
- オッズ台帳・Fairness(監査)リンクは全パック導線に露出する。
- 画面に表示するティアには対応する確率の開示必須(C-6)。
- 「transparent odds」の文言はオッズが実データに接続されるまで封印(接続後に復活。catalogAdapter のメモ参照)。
- カタログ説明文(tagline / description / topCard)は全パック仮 — 実データ接続時に実際の中身に基づいて全書き直し。それまで外部に見せない。

## C-10. 実装規約(コンポーネント・技術前提)

- スタックは Expo 54 React Native(iOS/Android/web)。CSS変数は使えないため、トークンの実装上の正は `src/tokens/sg.ts`(C-3 の値を verbatim 転記・現地調整禁止)。
- 色のハードコードHEX禁止(トークン参照のみ)。
- **新規実装での legacy トークン(ph/colors.ts・Outfit/brandFont・spacing.ts)の使用は 2026-07-31 付で禁止**(既存分の撤去は KNOWN_ISSUES T4)。
- スペーシングは 8pt(`sg.space` に一本化: 4/8/16/24/32/48/64)。角丸は panel 13 / btn 10 / tag 6 の3種のみ。
- ティア描画は `SgTierTag` が唯一の経路(独自実装禁止)。カード→ティアはデータのみ(名前・金額から推測しない。現状の唯一のリンクは `isChase`)。**UNKNOWN≠BASE**: データ無しは装飾ゼロで描画。
- `SgData` は数値専用(商品名・日付は本文書体)。
- コンポーネント配置: `ui/`=汎用 / `pack/`=ドメイン / `home/sg/`=画面別 / `_archive/`=退避(参照禁止)。`shared/` から `src/` を import しない。`prototypes/`・`marketing/` はプロダクトコード外。
- 開封 ring シーンは :3000 の Vite が配信(web=iframe / native=WebView)。`npm start`(scripts/dev.mjs)が Vite+Expo を同時起動。
- 開封演出の設計原典は `docs/opening-spec.md`(正本のみ。複製ファイルは削除済み)。3Dフラップ移植(prototypes/opening-3d/PORTING-NOTES.md)の pre-wiring は**ティア4段(C-6)前提に読み替える**(同メモ内の6段表記は旧版)。
- Result 画面は task1-result-screen-spec.md 準拠(開封フロー未配線・MOCK 表示中)。

## C-13. 用語集

同じ概念に複数の名前を付けない。以下の語を必ず使う。

| 使う | 使わない | 理由 |
|---|---|---|
| **Points** | Coins / Credits / Cash / Tokens | 現金や暗号資産との混同を避ける。Coins は暗号資産、Credits は融資を連想させる |
| **Trade in** | Buyback / Buy back / Cash out / Cash in | ポイントとの交換であり、現金での買い戻しではない |
| **Listed value** | Market value / Retail value | 自社が設定した値であることを明示する |
| **Tier** | Rarity | カードに印刷されたレアリティ(SR / SAR 等)と区別する |
| **MYTHIC / LEGENDARY / EPIC / BASE** | chase / hit / base、common / rare / uncommon、N/R/SR/SSR/UR、mythic〜common の5値enum | §6 |
| **Vault** | Storage / Locker | |

### 数値の書き方

# 第2部 JAPAN ELEMENTS(和方針)

> 旧§1の「伝統和記号の全面禁止」と旧§5-8 は、本方針に**置換**された(2026-07-31 人間承認)。旧規定の全文は docs/design-rules-archive.md。

## J-1. レジスター指定

和要素は「禁止」ではなく「レジスター指定」で扱う。

- **NG(本物志向の伝統)**: 漆・和紙・墨などの工芸素材コンセプト、神社の荘厳な写真表現、わびさび的ミニマリズム、筆文字。米国若年層に読解されず「古く」映るため。既定テーマの URUSHI ARCHIVE という概念・命名はこれに該当するため見直し対象(視覚トークンの黒+金は維持してよい。変えるのは概念語彙)。
- **OK(インバウンド記号)**: 桜、富士山シルエット、赤鳥居のアイコン化、渋谷/東京の夜景、カタカナ、提灯。ステレオタイプであるほど良い。米国客層にとって認識コストゼロの「日本フレックス」として機能する。
- **調理の原則**: 記号はフラット/ネオン/ポップに調理し、荘厳・写実・工芸的な調理をしない。例: MYTHIC演出の桜吹雪、バナーの富士シルエット+ネオン、DIRECT FROM TOKYO バッジの鳥居アイコン。
- 現行の鳥居×富士バナーは「差し替え」ではなく「**再調理**」候補(ムーディー写真→フラット/ネオングラフィック)→ KNOWN_ISSUES T7。

## J-2. カタカナ層(日本語表現の一本化)

- 日本語性はカタカナ・和文マイクロコピー(「深夜ドロップ」等)を等幅英字と併記して表現する。
- 「引」漢字透かしは**廃止確定**(2026-07-31。経緯は docs/design-rules-archive.md)。日本語表現は本カタカナ層に一本化する。

# 第3部 PLANNED(実装待ち・強制外)

> **本章は実装時まで強制されない。日常実装のチェック対象外。**着手時は対応するタスク(KNOWN_ISSUES のタスク登録)を先に消化すること。

## P-1. インタラクション物理(旧§9 未実装分)

開封という中核体験は「色」より「手触り」で差がつく。Apple Human Interface / Fluid Interfaces の原則の PullHub 翻訳。**着手時の最初のタスクは T9(RN 換算表の作成。C-7 組版詳細を含む)。**

- 押下即応: 全タップ要素は pointer-down の瞬間に反応(`:active { transform: scale(.97) }`、100ms以内)。touch-up待ちの反応は死んで見える。
- 開封は「引く」ジェスチャ: パックを指で1:1追従ドラッグ(掴んだ位置を尊重)→ 閾値超えで開封。コミット/キャンセル判定は離した位置ではなく**速度の符号**で。離した瞬間の速度はスプリングに引き継ぐ(velocity handoff)。
- スプリング既定値: 通常UIは damping `1.0` / response `0.3–0.4`(バウンス無し)。運動量を伴う操作のみ damping `~0.8`。固定durationのkeyframesはジェスチャ系に使わない(中断できないため)。
- シートは閉じ途中でも掴んで戻せる(開封スキップは実装済み — C-8)。
- 境界はラバーバンド: リスト端・シート限界は硬く止めず漸増抵抗。
- 触覚/音はティアに同期: BASE = 無し、EPIC / LEGENDARY = 軽い単発、MYTHIC = 段階エスカレーション。視覚・音・触覚は同一フレームで発火。意味のある瞬間以外に足さない。
- reduced-motion時: スライド/スプリング→短いクロスフェード。開封は静的リビール+結果の色表示は維持。

## P-2. 開封の色エスカレーション(旧§6 演出規定)

BASE は無彩色 → LEGENDARY 金 → MYTHIC ネオン朱(グロー)の順に照度が上がる。
虹/ホロ表現を使う場合も MYTHIC 演出の最終フレーム限定(C-5-2 の例外)。
