## 1. ブランドコンセプト — "Midnight Tokyo"

- PullHubは米国向けオリパアプリ。実物の鑑定済みトレカをデジタル開封し、発送 or 即時買取。
- 世界観は **「深夜0時の東京にある、閉店後も灯りのついた高級カードショップ」**。騒がしいネオン街ではなく、ショーウィンドウの静けさ。
- **伝統和の記号(鳥居・富士山・神社・和柄・筆文字)は使用しない。** 若年層にとっての日本はネオ東京・アニメであり、日本性は次で表現する:
  - 毎晩 **00:00 JST のドロップ**(時刻自体がブランド装置)
  - 漢字1文字の輪郭透かし(既定は「引」= pull。塗りtransparent + `-webkit-text-stroke: 1.5px var(--ph-neon-glow)`)
  - カタカナ・日本語のマイクロコピー(「深夜ドロップ」等)を等幅英字と併記
- 三色の意味: **黒=夜、金=価値、ネオン朱=いま起きている瞬間**。
- パレット名の "Neon Torii" は名称であり、視覚モチーフとしての鳥居は §5-8 で禁止。

## 2. ペルソナ前提(要約)

米国オリパ顧客は4部族: P1ブレイク民(ライブ配信購買層・最大)、P2ポケモン世代投資家(ノスタルジア+資産)、P3ガチャネイティブ(Z世代、54%がアニメファン)、P4ハイプ転売系(スニーカー文化)。
**N2は全部族が拒絶しない唯一のバランス**のため既定に採用。部族別の尖りはイベントスキン(§9)で出す。詳細は別紙『米国オリパ潜在顧客 徹底分析』。

## 4. 役割ルール

| 色 | 役割 | 使う | 使わない |
|---|---|---|---|
| `--ph-bg` 黒 | 夜 | 画面の地(面積85–90%) | — |
| `--ph-surface`系 | 灯り | カード/パネル/入力欄 | 全面に敷く |
| `--ph-gold` 金 | **価値** | 価格・主要CTA(1画面1つ)・Hitランク・残高・ロゴのアクセント | 本文/汎用ボーダー/広い背景 |
| `--ph-neon` 朱 | **瞬間** | DROP LIVE・CHASE・カウントダウン・開封/レア演出。**面積2%以下・必ずグロー付き** | CTA/本文/常設ナビ/広い面 |
| `--ph-success` 緑 | 検証 | 監査済み・在庫残数・成功 | 装飾 |

- 数字は全て等幅フォント: 価格・確率・残数・証明書番号・カウントダウン・残高。
- 金とネオンの同一要素での併用禁止。
- エラーとネオンの区別: エラー=フラット+アイコン+説明文(フォーム/トースト内)。ネオン=グロー+等幅大文字ラベル。

## 5. 禁止事項(AI味の既定値)

grep対象。1つでも残っていたら差し戻し:

1. `#FFFFFF`(最明色は `--ph-text`)
2. 高彩度2色グラデーション(紫→シアン、シアン×マゼンタ等)を文字・ボタン・広い面に使うこと — 生成AIが統計的に回帰する「AI製の指紋」であり、本項はその再発防止テスト(C1案不採用の教訓)。**例外: CHASE開封演出の最終フレームの虹/ホロのみ可(§6)**
3. glassmorphism = **装飾としての**半透明blurカード(機能的クロームの半透明は§9で条件付き許可)
4. 絵文字アイコン(💎🔥⚡🎁等)
5. 常時アニメーション(バウンスするCTA・点滅バナー)
6. 「#1」「Insane」「Don't miss out」等の検証不能な誇張コピー
7. 偽の緊急性(実在しないタイマー・在庫)— 法務リスク兼ブランド毀損
8. 鳥居・富士・和柄・筆文字(旧コンセプトの残骸)

## 6. ティア(ガチャ文法)

ティアは「引きの良さ」を表す。パック側の属性であり、カードの属性ではない。
カードに印刷されているレアリティ(SR / SAR / AR / UR / RR 等)とは別物で、
UIのラベルは "RARITY" ではなく "TIER" を使う。
カードの印刷レアリティは、ティアとは別の欄に表示する。

| ティア | 色 | 形 |
|---|---|---|
| MYTHIC | `--ph-neon` + `--ph-glow-neon` | 塗りつぶしタグ |
| LEGENDARY | `--ph-gold` | 塗りつぶしタグ(`--ph-on-gold` 文字) |
| EPIC | `--ph-gold` | 枠線のみ |
| RARE | `--ph-muted` | 枠線のみ |
| UNCOMMON | `--ph-muted` | 文字のみ |
| COMMON | `--ph-muted` @50% | 文字のみ |

色を持つのは上位3段のみ。下位3段は「当たっていない」という同じ意味なので
色を与えず、語とウェイトだけで区別する。6段に6色を割り当てないこと。
新しい色を追加しないこと。

オッズ表もこの6段と同じ段数・同じ名前にする。
画面に表示するティアには、必ず対応する確率が開示されていなければならない。

開封演出の色エスカレーション: COMMON〜RARE は無彩色 → LEGENDARY 金 →
MYTHIC ネオン朱(グロー)の順に照度が上がる。
虹/ホロ表現を使う場合も MYTHIC 演出の最終フレーム限定。

### NEON BRUTALスキン(差し替えは見出しのみ)

| 役割 | 第一候補 | 代替 | 備考 |
|---|---|---|---|
| 見出し | **Chakra Petch** 700(大文字) | Rajdhani / Saira SemiCondensed | 角張った工業感。本文・等幅・日本語は**ブランドと同一**(信頼シャーシ) |

### 禁止書体

- Inter / Roboto / Open Sans の単独使用(「選ばなかった」印 = AI味)
- Orbitron / Audiowide / Michroma(「AIのSF既定値」。サイバー系で最初に出てくる安易な選択)
- Playfair Display(高級テンプレの既製品感)

### 組版ルール(サイズ別に必ず変える)

- 字間はサイズ依存: 見出し(32px+)は `-0.01〜-0.02em`、本文は `0`、等幅の大文字ラベルは `+0.12〜0.17em`
- 行間もサイズ依存: 見出し `1.05〜1.12`、本文 `1.6〜1.7`、データ行 `1.4`
- 階層は サイズ+ウェイト+行間 のセットで作る(サイズだけで殴らない)
- 余白・レイアウトは `rem/em` 基準(ユーザーの文字サイズ設定に追従して崩れないこと)

## 8. モーション

- 常時動いてよいもの: スラブのフォイル光沢スイープ(5.5s周期・1画面1箇所)、LIVEドットの明滅(1.6s)。以上。
- 開封演出: ここだけ演出全開可(スローダウン→色エスカレーション→結果)。心理学的にも「期待」の3秒が価値の中心。
- 全アニメーションは `prefers-reduced-motion: reduce` で停止。実装物理は§9。

## 9. インタラクション指針(Apple流の実装物理)

開封という中核体験は「色」より「手触り」で差がつく。以下はApple Human Interface/Fluid Interfacesの原則をPullHubに翻訳したもの。

- **押下即応**: 全タップ要素は pointer-down の瞬間に反応(`:active { transform: scale(.97) }`、100ms以内)。touch-up待ちの反応は死んで見える。
- **開封は「引く」ジェスチャ**: ブランド名の通り、パックを指で1:1追従ドラッグ(掴んだ位置を尊重)→ 閾値超えで開封。コミット/キャンセル判定は**離した位置ではなく速度の符号**で。離した瞬間の速度はそのままスプリングに引き継ぐ(velocity handoff)— 指とアニメの継ぎ目を消す。
- **スプリング既定値**: 通常UIは damping `1.0` / response `0.3–0.4`(バウンス無し)。フリックや開封リリース等**運動量を伴う操作のみ** damping `~0.8`。CSSの固定duration keyframesはジェスチャ系に使わない(中断できないため)。
- **中断可能性**: 開封演出は常にタップでスキップして結果へ。シートは閉じ途中でも掴んで戻せる。演出がユーザーを待たせ始めたら負け。
- **境界はラバーバンド**: リスト端・シート限界は硬く止めず漸増抵抗。
- **機能的半透明の条件付き許可**: §5で禁止したのは「装飾ガラスカード」。スクロール下のトップバー/ボトムシート等の**機能的クローム**は `rgba(0,0,0,.72) + backdrop-filter: blur(20px)` まで可。材料の重ねは1層まで、`prefers-reduced-transparency` で不透明化。
- **触覚/音はレアリティに同期**: BASE=無し、HIT=軽い単発、CHASE=段階エスカレーション。視覚・音・触覚は**同一フレーム**で発火(ズレは安物感)。意味のある瞬間以外に足さない。
- **reduced-motion時**: スライド/スプリング→短いクロスフェード。開封は静的リビール+結果の色表示は維持。
