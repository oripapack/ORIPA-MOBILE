# 実写アセット仕様書(スラブ・包装・ステージ)

lab `/redesign` の「Just Pulled」スラブ表示を実写に差し替えるためのアセット仕様。
参照した技法は3つのみ — **①実物スラブ写真 ②破れたパック包装のオーバーレイ合成 ③台座+反射のステージ演出**。
参照元(社外スクリーンショット)の**レイアウト・構図・トレードドレスは複製しない**。

## 置き場所とファイル名規約(自動検出)

`prototypes/next-ui-lab/public/assets/slabs/` に置くと、`/redesign` が**リロード時に自動で拾う**。
該当ファイルが無いスロットは従来の CSS プレースホルダーに自動フォールバックする(コード: `app/redesign/page.tsx` の `readSlabAssets`)。

| ファイル名 | 対応 | 必須/任意 |
|---|---|---|
| `slab-01.png` 〜 `slab-04.png` | Just Pulled の1〜4枚目のスラブ実写 | スロット単位で任意 |
| `wrap-01.png` 〜 `wrap-04.png` | 同番号カードの「破れ包装」オーバーレイ | 任意(スラブがある時のみ意味を持つ) |
| `stage-01.png` | 全カード共通のステージ(台座+反射) | 任意(1枚) |
| `_sample-mock-slab.png` | 合成のMOCK見本(自動検出の**対象外**。動作確認用に `slab-01.png` へコピーして使う) | 同梱 |

## アセット仕様

### スラブ実写(slab-NN.png)
- **背景透過 PNG**。ケース輪郭で切り抜く(**影は含めない** — 影・台座は CSS/ステージ側で付ける)
- **長辺 1600px** 以上、sRGB
- **光源は左上45度で全カット統一**(混在すると並べた時に嘘になる)
- 被写体は**自社在庫の実物スラブのみ**(下記ガードレール)

### 破れ包装オーバーレイ(wrap-NN.png)
- 透過 PNG。**裂け目の内側が透けている**こと(下のスラブが覗く)
- キャンバスは対応する slab-NN と同一(そのまま重ねてレジストレーションが合う状態で入稿)
- 光源方向はスラブと同じ左上45度

### ステージ(stage-01.png)
- **縦横比 2:3**。台座と反射は焼き込みでよい
- 暗部で馴染む色域(#000〜#17171C 周辺)。明るい床・白背景は不可(C-5-1)

## 撮影チェックリスト

- [ ] マットな黒背景(反射する黒アクリルはステージ用カットのみ)
- [ ] ライトは左上45度1灯+レフ。全カットで固定
- [ ] スラブ表面のグレア回避(偏光フィルタ or 角度調整)。ラベル文字が読めること
- [ ] 撮影者・照明の写り込みチェック(ケースは鏡になる)
- [ ] レンズ正対・歪みなし。長辺1600px以上で書き出し
- [ ] ホワイトバランス固定・sRGB
- [ ] 切り抜きはケース輪郭ぴったり。影・床は含めない

## ガードレール(C-5-9)

- **実在の他社カード写真・ストック画像・ネット上の拾い画像の流用は禁止。自社在庫の実写のみ。**
- プレースホルダー段階では MOCK 3点セットを維持(モックデータの MOCK 命名・ファイル冒頭注記・KNOWN_ISSUES 記録)。同梱の見本 `_sample-mock-slab.png` は権利物を含まない合成 MOCK。
- 権利未確認の実写(キャラクター等)は外部公開素材(スクショ共有含む)に使わない。
